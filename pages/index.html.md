---
title: Firehose | Build realtime web applications
---

Firehose is a __minimally invasive way of building realtime web apps__ without
complex protocols or rewriting your app from scratch. It's a dirt simple
pub/sub server that keeps client-side Javascript models in sync with the server
over WebSockets or HTTP long polling.

# Documentation

- [**Firehose v1 docs**](/v1/) — the current, released documentation.
- [**Firehose next docs**](/next/) — documentation for the upcoming release (work in progress).

# Get started

    $ gem install firehose
    $ firehose server
